# CA-S07 Diagnostics/Template Cleanup Checklist

Use this checklist to validate diagnostics/template simplification and contract alignment.

## Required checks

- template outputs match current component contract surfaces
- no stale/retired dependency markers in active diagnostic templates
- deterministic PASS/WARN/FAIL behavior with actionable next steps

## Output packet

- checked template list
- mismatch count
- unresolved contract count
- closeout verdict
