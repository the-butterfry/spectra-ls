# Getting Started

This page helps you pick the right lane quickly.

## 5-minute orientation

1. Read [`README.md`](https://github.com/the-butterfry/spectra-ls/blob/main/README.md) for current direction.
2. Pick one path below.

## Pick your lane

### I’m installing Spectra

Go here, in order:

1. [Install on Your Own Home Assistant](Install-on-Your-Own-HA)
2. [User Setup, Deploy, and HA Integration](User-Setup-Deploy-and-HA-Integration)
3. [Operations Runbooks](Operations-Runbooks)

You’re done when audio + lighting both work and room/target options are populated.

### Something broke and I need help

1. [Welcome, README, and Bug Workflow](Welcome-README-and-Bug-Workflow)
2. [Operations Runbooks](Operations-Runbooks)
3. [.github/ISSUE_TEMPLATE/bug_report.yml](https://github.com/the-butterfry/spectra-ls/blob/main/.github/ISSUE_TEMPLATE/bug_report.yml)

You’re done when the report has deterministic repro steps, expected vs actual, and useful evidence.

### I’m contributing code/docs

1. [`CONTRIBUTING.md`](https://github.com/the-butterfry/spectra-ls/blob/main/CONTRIBUTING.md)
2. [`docs/developer/DEVELOPER-INSTRUCTIONS.md`](https://github.com/the-butterfry/spectra-ls/blob/main/docs/developer/DEVELOPER-INSTRUCTIONS.md)
3. [Release and Changelog Process](Release-and-Changelog-Process)

You’re done when docs parity and verification evidence are included in your change set.
